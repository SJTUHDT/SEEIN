# 原生工具集成

完整功能、上游及边界见 [截图录屏](plugins/capture.md) 和 [效率工具](plugins/efficiency.md)，构建环境和对应源码见 [BUILDING.md](BUILDING.md)。

上游固定版本记录在 vendor/tools/sources.lock.json。SEEIN 使用当前用户的命名管道处理动作、设置和窗口内快捷键；程序作为受管理的子进程运行。工具操作保留原生 Qt/WinUI 界面，设置与全局快捷键统一放在 SEEIN。

发布源码包含固定上游、实际修改后的完整文件、原许可证与 SEEIN 补丁。开发工具链和构建缓存不安装到应用中。翻译配置独立于大肥鱼，密钥使用当前用户 DPAPI，不从读取接口返回。
