# SEEIN 2.2.1 · .NET 10

- 保留原有 WPF 界面、字体、布局与按功能下载插件方式，主程序升级至 .NET 10。
- 随包提供运行时，无需用户另装 .NET。
- 无效传感器读数按不可用处理，避免 NaN 或无穷值中断后台通信。
- 后台服务和桌面程序统一共享桌面运行时，避免 WindowsBase 依赖冲突。

下载 `SEEIN-2.2.1-win-x64-Core.zip` 安装本体，在应用设置 → 插件管理中下载安装所需功能。升级前请退出 SEEIN；安装过程保留受支持的插件和用户数据。新的插件包要求 2.2.1 或更新的主程序。

本版本不迁移 WinUI，不改变原有 WPF 界面。运行时随包提供。完整源码、上游声明、签名插件与 SHA256SUMS 随 Release 提供。
