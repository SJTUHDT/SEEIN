# SEEIN 2.2.0 · 在线插件中心

**普通使用只需下载 `SEEIN-2.2.0-win-x64-Core.zip`。** 安装本体后，到「应用设置 → 插件管理」勾选需要的功能，点击「下载安装并重启」。

- 副屏与主题、应用监控各保留一个完整插件。
- 设备控制六项：显示器、采集播放、RGB、风扇、路由器、挂灯。
- 小工具六项：截图录屏、效率、桌宠、工作台、AstrBot、QQ 后台。
- 公共依赖自动处理，先下载并验证完整文件，再一次授权、一次维护与重启。支持取消、缓存复用和失败恢复。
- 2.1 同发布者整包在 Core 更新时保留，管理页自动预选对应子项，设置、快捷键和历史保留。
- README 加入十张匿名实机图：应用/进程名称、对应图标和路径被替换，原有统计数值和图表保留。

Release 的插件包和签名目录由应用使用；源码、许可证和原生依赖源码供开发及许可查阅，不需要全部下载。使用 SHA256SUMS.txt 校验，体积组成见 COMPONENTS.json。内嵌网页需要 WebView2，硬件适配以兼容性文档为准，功耗为估算。Snow Shot、Pane、dsh-pet、OpenRGB 等上游声明和对应源码随发行保留。2.1.0 历史发布继续保留。
