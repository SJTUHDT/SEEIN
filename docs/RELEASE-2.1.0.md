# SEEIN 2.1.0

SEEIN 的首个公开版本：Windows 桌面仪表盘、耗能日历与六个可选插件。

## 下载

- 只需本体或希望按需添加：Core ZIP。
- 一次安装全部公开功能：Full ZIP。
- 已有 2.1.0 本体：按需下载六个 `.seeinplugin`，在应用设置中导入。
- 校验程序：SHA256SUMS.txt；查看实际组成：COMPONENTS.json。
- 开发及许可证：SEEIN 源码快照、修改后的原生工具源包和第三方对应源码附件。

详细能力见仓库 README 和 docs/plugins 下的六份说明。Snow Shot、Pane、dsh-pet、OpenRGB 等上游作品保留来源及原许可证。桌宠为 SEEIN 原生子进程，不随包带 Electron；肥鱼后端另行部署。硬件适配以已验证型号及驱动能力为准，功耗为估算。

首次使用需配置智能设备地址及外部工作台路径。内嵌网页需要 WebView2。安装方法、公开测试和实机验收边界见 INSTALL.md、ACCEPTANCE.md。请先完成手头的录制、导出再更新或退出。
