- 本轮没有替换维护者正在运行的个人正式版，没有修改其服务、硬件策略、授权和历史回滚版本。
- 本轮没有通过真实 UAC/Windows 服务执行安装维护，也没有重测风扇/RGB 写入、挂灯授权、路由器登录、UVC 实际音视频、截图/录制/OCR 或桌宠手感的完整人工流程。相关能力沿用原实现，拆分后的程序集和入口进行了独立构造验证；硬件范围见 COMPATIBILITY.md。
- 托管组件从当前公开源码编译；原生截图、效率、OpenRGB 与编解码器使用锁定版本、已校验输入，其对应源码随发行保留。本次未在全新电脑从零重建全部 C++/Rust/Qt 工具链，也不承诺逐字节可复现构建。
- 在线目录不兼容新宿主要求或 GitHub 不可达时，使用本机已验证目录并提示，现有功能可继续使用；不绕过签名或自动升级本体。
