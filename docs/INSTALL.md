# 安装、升级与插件

1. 从 Releases 下载 Core 或 Full，核对 `SHA256SUMS.txt`，解压到临时目录。
2. 用管理员 PowerShell 7 运行解压根目录的 `Install.ps1 -PackageRoot '<解压根目录>'`。默认安装到系统 `Program Files\Seein`；要换盘可指定 `-InstallParent 'D:\Program Files'`。更新时选择与现有版本相同的位置。后台需要服务权限；不要直接覆盖正在运行的 DLL。
3. 从开始菜单或托盘打开 SEEIN。主窗口 × 收起到托盘，「退出托盘程序」结束桌面端子进程，硬件后台继续运行。
4. 使用 Core 时，在「应用设置 → 插件管理」导入同次发布的签名 `.seeinplugin`。导入、停用和卸载通过安全重启完成，录制/导出未结束时先完成相关操作。

完整包包含六个公开插件。Core 不包含这些可选组件；硬件或外部服务未配置时不代表安装失败。内嵌网页需 WebView2 Evergreen Runtime，可从微软官方渠道安装。

升级前保存进行中的录制、导出和设备草稿。安装器验证清单，使用临时事务替换；失败按事务恢复。自编译插件需使用与自编译宿主匹配的公钥，官方包与自建签名不能混用。

设备地址首次填写：路由器页显示管理地址输入；挂灯扫码后确认设备与局域网地址。大肥鱼位置在小工具的「连接设置」填写。请勿导入他人的授权或个人数据库。

卸载程序与插件均不默认删除个人历史；确需清除时先停止软件并备份，再手动处理 [数据目录](PRIVACY.md)。硬件控制异常先使用「交还硬件控制」，不要通过反复删除配置猜测状态。
