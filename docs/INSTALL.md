# 安装、在线插件与升级

## 首次安装

1. 从本仓库 2.2.1 Release 下载 `SEEIN-2.2.1-win-x64-Core.zip`，用 `SHA256SUMS.txt` 核对，再解压。
2. 在管理员 PowerShell 7 中运行根目录的 `Install.ps1 -PackageRoot '<解压目录>'`。默认安装到系统 Program Files\Seein；换盘使用 `-InstallParent 'D:\Program Files'`。更新时选择原位置，勿直接覆盖运行中的 DLL。
3. 从开始菜单或托盘打开 SEEIN，到「应用设置 → 插件管理」勾选功能，点击「下载安装并重启」。

本体自带 .NET 10。内嵌网页需系统 WebView2 Evergreen Runtime；选择效率工具才下载其 .NET 10 与 Windows App SDK 依赖。

## 在线安装

四个大项、十四个可选功能。设备控制六项分别为显示器设置、采集播放、灯效、风扇、路由器和挂灯；小工具六项分别为截图录屏、效率、桌宠、工作台、AstrBot 和 QQ 后台。副屏主题与应用监控各保留一个完整插件。

勾选项显示版本、用途和体积，下方显示自动加入的共享组件。下载并发最多两个；失败或取消时校验完整文件可复用，不完整临时文件会清理；安装成功后清理已用下载包，避免长期重复占用磁盘。先完成全部下载与验证，再申请一次系统授权、统一提交安装。取消授权不修改当前安装。

安装前结束录制和导出，保存草稿。安装器正常退出托盘与子进程，按需维护后台；事务失败或中断可恢复原插件和启用状态。主窗口 × 只收到托盘，不等于退出程序。

## 停用、卸载与离线包

右侧停用/启用保留文件；取消已安装功能的勾选表示卸载，最后统一提交。个人设置与历史均保留。共享包由依赖自动处理，不应单独删除其目录。

离线时可导入同版 `.seeinplugin`。有依赖的功能须先导入依赖包：截图与效率需要 tools-common；路由器需要 webview-runtime；桌宠需要 companion-common 与 webview-runtime；三个后台页面需要 companion-web，而 companion-web 需要 companion-common、webview-runtime。所有包均来自同次 Release，逐包导入会各执行一次维护；在线多选可一次完成。

## 从 2.1 升级

Core 更新会保留同发布者公钥的已安装插件与用户数据。离线时旧整包可继续运行；进入插件中心后，旧设备/桌宠整包自动映射并预选等价小项，原停用状态保留。点击一次安装即可转换，完成前不删除旧包。新旧实现不会重复启用。

若现有插件与本体公钥不同，安装器停止并保留原安装。自建发行与官方签名不能混用，请使用同一发布者的连续构建。2.1.0 的历史 Release 不覆盖。

## 首次设备配置

路由器与挂灯地址由用户填写，挂灯需本人授权。大肥鱼目录与本机后台地址在连接设置填写；修改目录后重新启动桌宠。首次风扇和灯效不默认接管未知设备，异常时先交还控制。

卸载不默认删除历史。确需清除时先停止并备份，再按 [数据目录](PRIVACY.md)处理。
