# 已验证范围与限制

目标为 Windows 10/11 x64（项目目标 Windows API 为 10.0.19041）。发布验收记录列出实际执行环境，不把目标平台当作所有硬件组合均已验证。

| 功能 | 当前已知范围 | 限制 |
|---|---|---|
| 副屏 | VID_33C3/PID_F101、1920×462 协议 | 其他控制器、尺寸及固件须单独适配 |
| 显示器 | 驱动提供的 DDC/CI 能力 | 转接、扩展坞及型号影响可写项 |
| 主板灯效/风扇 | 已验证 MSI MS-7E61 / Nuvoton 通道 | 专门控制路径不是通用主板驱动 |
| 显卡 | Radeon RX 9070 XT 的已验证读取/灯效路径 | ADLX 写入受驱动和模式限制，未通过场景不保证可写 |
| 路由器网页 | 中兴晴天 AX3000 | 其他型号原厂页面和自动登录行为不同 |
| 米家挂灯 | 米家显示器挂灯2 | 不自动承诺全部米家设备兼容 |
| 采集播放 | UVC/USB 音频，当前匹配 UGREEN 45647 | 只请求驱动报告的模式，不保证任意设备高帧率 |
| 肥鱼后台 | 本机已部署的大肥鱼、AstrBot、SnowLuma | 需用户配置、登录和维护外部服务 |

首次启动风扇与灯效策略默认未启用。请先读取能力并确认设备，再主动接管。功耗估算默认基线 74W、效率 90% 是可调整的估算参数，不是对所有电脑的校准结果。
