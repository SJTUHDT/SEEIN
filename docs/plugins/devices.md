# 设备控制

插件 ID：`devices` · 版本：2.1.0 · 最低宿主：2.1.0 · 插件 API：1

入口：**设备控制**。通过应用设置导入 `devices-2.1.0.seeinplugin`，重启后生效。停用不删除设置，卸载保留用户数据。

## 显示器

通过 DDC/CI 读取设备支持的亮度、对比度、RGB 增益、输入源和电源选项。滑块即时生效；输入源和电源使用确认按钮。支持输入源昵称、DP1 快捷切换与回读确认。显示器需启用 DDC/CI；扩展坞和转接线可能影响可用性。

## 灯效

整机、设备、分区、逐灯控制；可用硬件模式、软件灯效、亮度、速度、颜色与默认场景。支持灯珠数量配置、分区同步、音乐电平响应、颜色校正和渐变。部分 MSI 主板具有专门的原生模式和闭环水波播放路径，这些不代表所有主板兼容。

OpenRGB 1.1 在本机回环端口运行，负责其支持的灯光设备访问。SEEIN 实现场景、配置、软件效果、SDK 通信和已验证板卡的控制逻辑。底层是 OpenRGB 的部分保留原作者和 GPL-2.0-or-later 许可，未宣称另造完整硬件驱动库。

## 风扇

冷排、水泵、机箱及支持显卡的温度、RPM 和控制权总览；逐通道固定占空比/温度曲线、配置档、草稿、模拟、趋势、诊断和交还硬件控制。草稿只有应用后才写入，传感器失效或控制权异常会尝试恢复自动控制。

主板能力取决于传感器与控制器；AMD 显卡使用驱动安装的 ADLX，权限、驱动模式和保护开关可能限制写入。未经验证的设备不能保证软件控制；不随包提供或替换 AMD 驱动。首次启动不自动接管。

## 路由器与米家挂灯

路由器为原厂管理网页整页嵌入。首次设置管理地址，手动登录成功后以 Windows 当前用户 DPAPI 加密记住密码；同源页面最多自动尝试一次。已验证的网页行为针对中兴晴天 AX3000，其他型号不保证自动登录兼容。

米家显示器挂灯2支持扫码授权、局域网开关、亮度和色温，保存/重命名/更新/删除预设；应用预设同时开灯。开关与每个预设均可在应用设置中分配快捷键。授权流程参考 MIT 许可的 Xiaomi-cloud-tokens-extractor，以原生 C# 集成，不携带 Python 授权工具。退出挂灯页面停止轮询。

## 采集卡影音播放

在「采集播放」选择视频设备、模式、对应 USB 音频和声音输出。可内嵌播放、弹出、召回和全屏，F11/ Esc 切换全屏；保持同一采集会话。声音跟随系统音量，切页或最小化后可继续播放音频，不可见视频停止解码与绘制。停止或退出会释放设备。

使用 FlashCap 1.13.0、Vortice.Windows 3.6.2 和 NAudio 2.2.1；SEEIN 实现会话管理、单帧等待队列、WIC 解码、D3D/Direct2D 显示与有界音频缓冲。未捆绑 OBS 或另一个播放器。仅使用驱动报告的模式，不能保证任意采集卡达到 1440p120；不提供录制、推流、手柄和 Switch 开关机功能。帧处理耗时不是端到端延迟。

## 快捷键、数据与排查

显示器 DP1、挂灯开关和预设的快捷键统一在「应用设置 → 快捷键管理」，支持允许的单键及组合键，冲突保留原绑定。

风扇、灯效策略位于 `%ProgramData%\Seein\settings.json`；显示器、智能设备及采集播放偏好位于 `%LOCALAPPDATA%\Seein`。账号授权不进入发布包，DPAPI 文件不能直接复制给另一 Windows 用户使用。

设备占用先关闭其他采集源；SEEIN 不会终止 OBS。风扇/灯效出现控制冲突先交还控制，确认其他控制软件和硬件能力。路由器地址为空时显示配置入口，不会默认访问开发者网络。

## 体积与运行占用

发布附件中的 `COMPONENTS.json` 提供本轮实际文件字节数；`ACCEPTANCE.md` 区分已验证与未验证场景。运行占用随设备、主题、录制或播放负载变化，不承诺固定 CPU/内存数值。
