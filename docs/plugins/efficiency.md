# 效率工具与文件搜索

## 2.2 安装方式

入口：小工具 → 效率工具。插件中心自动加入 tools-common；Everything 和工具自己的 .NET 10 运行时仅随本功能下载。


插件 ID：`efficiency` · 版本：2.2.0 · 最低宿主：2.2.0 · 插件 API：1

入口：**小工具 → 效率工具；应用设置 → 快捷键管理**。通过应用设置导入 `efficiency-2.2.0.seeinplugin`，重启后生效。停用不删除设置，卸载保留用户数据。

## 功能

- 快速启动器：查找和启动应用，常用项目、收藏及配置的搜索站点。
- 剪贴板历史：支持原工具的记录类型、容量和隐私偏好，按需启用。
- Everything 本地文件搜索及索引就绪提示。
- 在打开/另存为对话框跳转到已打开或选择的文件夹。
- 批量重命名和定时关机；执行实际修改或关机前应确认界面选项。
- 能力开关、界面主题、字体、图标及玻璃效果等原工具设置。

## 上游与集成

基于 LBEILC 的 **Pane 0.1.606**，固定提交 `6f8be9632bd4d4e6d27240db5e18ea5923327476`，保留 GPL-3.0 许可。操作窗口使用 WinUI 原生界面，SEEIN 负责设置桥、命名管道、动作、快捷键、子进程与存储集成，并维护搜索站点及搜索栏对齐相关修改。

文件索引使用 Everything 1.4.1.1032；随包保留 voidtools 许可与来源，独立的 SEEIN 命名实例不接管用户自己运行的其他 Everything 实例。插件携带 .NET 10 和 Windows App SDK 依赖，不替换本体 .NET 8。

当前没有集成鼠标手势、超级面板与 Pane AI 模块。上游存在某个功能不代表 SEEIN 公开包已经支持；能力页只管理实际集成的部分。

## 使用

在统一快捷键页设置启动器、剪贴板、文件搜索、批量重命名、文件夹跳转和定时关机的呼出键。剪贴板可选择双击左 Alt，原有全屏策略继续生效；右 Alt 截图开关不是本插件的剪贴板键。

文件搜索首次需要索引服务和命名客户端就绪。安装器可按包内说明准备索引依赖；未就绪时提示准备，不影响已启用的剪贴板和启动器。关闭能力会停止对应动作并释放其全局快捷键。

## 数据、隐私与排查

偏好及历史位于 `%LOCALAPPDATA%\Seein\Tools\pane`，索引客户端数据位于 `Tools\everything`。剪贴板可能包含密码或个人信息，请合理设置记录范围，不分享完整数据库。搜索站点会打开用户选择的外部网址。

退出 SEEIN 会关闭其持有的工具与命名索引客户端；系统索引服务和用户独立实例有各自生命周期。搜索无结果先检查索引是否就绪、路径权限和能力开关。卸载保留历史和偏好。

上游：[Pane](https://github.com/LBEILC/Pane)、[Everything](https://www.voidtools.com/)。对应源码包含 SEEIN 实际修改、源版本及依赖记录。

## 体积与运行占用

发布附件中的 `COMPONENTS.json` 提供本轮实际文件字节数；`ACCEPTANCE.md` 区分已验证与未验证场景。运行占用随设备、主题、录制或播放负载变化，不承诺固定 CPU/内存数值。
