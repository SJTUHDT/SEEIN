# 应用监控与应用库

插件 ID：`applications` · 版本：2.1.0 · 最低宿主：2.1.0 · 插件 API：1

入口：**应用监控；应用设置 → 应用列表**。通过应用设置导入 `applications-2.1.0.seeinplugin`，重启后生效。停用不删除设置，卸载保留用户数据。

## 功能

- 日/周应用时长、活跃时长、应用排行和时间轴；可选择日期、显示全部项目并生成摘要。
- 按应用 CPU 时间、GPU 占用分摊 CPU/GPU 实测功耗，展示应用耗电、系统进程及基线与其他。
- CPU/GPU 平均占用、峰值、最低值，以及按应用的网络上传、下载和合计。
- 应用列表可展开进程，改名、换图标、改颜色、归并与隐藏；后台和系统进程按规则分组。
- 本体、受管理的桌宠/工具/网页进程归入 SEEIN，开发工具和无关外部副本不冒充正式应用。

## 口径

默认每 5 秒采样。应用运行时长是成员进程时间区间的并集，不能把多进程时长直接相加。应用时长可与整机运行时长不同。连续 40 分钟没有输入视为离开，托盘负责上报键鼠空闲状态。

应用功耗是分摊估算，不是对每个进程直接测电。未能归属的基线和电源损耗单列；传感器、权限及 GPU 引擎计数器会影响结果。网络优先使用 ETW；不可用时回退 TCP ESTATS，因此可见协议范围可能变化。

## 实现与使用

采样、进程归并、查询、数据库及图表由 SEEIN 实现，使用 Windows Toolhelp、PDH、ETW/ESTATS 等接口与 SQLite。没有捆绑另一个应用监控主程序。

在应用监控中切换时长、功耗、占用；在应用设置的应用列表中管理名称、图标及归并。调整归并会影响后续展示及对应历史迁移，请先确认目标应用。

## 数据与排查

`%ProgramData%\Seein\app-usage.db` 保存事件、聚合与元数据，分类规则和摘要也保存在该系统数据目录。卸载插件保留历史；安装包不含任何个人应用历史。

没有结果先检查后台连接、日期和隐藏阈值。网络/GPU 无读数不代表负载为零；查看权限和计数器可用性。摘要可能包含应用名称，分享前应自行检查。

## 体积与运行占用

发布附件中的 `COMPONENTS.json` 提供本轮实际文件字节数；`ACCEPTANCE.md` 区分已验证与未验证场景。运行占用随设备、主题、录制或播放负载变化，不承诺固定 CPU/内存数值。
