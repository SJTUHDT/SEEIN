# 原生桌宠与大肥鱼

插件 ID：`companion` · 版本：2.1.0 · 最低宿主：2.1.0 · 插件 API：1

入口：**小工具 → 桌宠／大肥鱼工作台／AstrBot 后台／QQ 后台**。通过应用设置导入 `companion-2.1.0.seeinplugin`，重启后生效。停用不删除设置，卸载保留用户数据。

## 桌宠

- 启动、停止、显示、隐藏；多个宠物、大小、位置及按宠物显示。
- 缓慢拖拽松手停在当前位置；只有松手速度超过阈值才抛出、飞行和下落，停顿后松手不会延用早先速度。
- 单次左键点击不切换状态，累计达到阈值才播放回应动画，默认 5 次。
- 原风格的图片预览菜单、动作、睡眠/唤醒、固定、初始位置和重载；透明区域命中与动画显示由原生窗口处理。
- 统一的宠物配置、外观、行为、物理、气泡和语音设置。

## 来源和 SEEIN 修改

基于 PC2005-cloud 的 **dsh-pet 0.4.9**，固定提交 `4e589f6dacabbd3170e91e7a213b2a7afff1a09b`。使用原动画、图片、声音、字体和默认配置，并移植拖拽、菜单与行为；原作者 MIT 许可证随素材提供。素材及第三方作品保留原有署名，不作为 SEEIN 自创角色出售或重新声明所有权。

当前由 SEEIN 的 WPF 原生子进程运行，**不随包带 Electron 或 Chromium 桌宠应用**。VP8/VP9 alpha 动画使用单独的 LGPL FFmpeg/libvpx DLL；GIF/WebP 使用现有渲染依赖。对应源码、编译参数及许可证随发布材料提供。

## 大肥鱼桥与后台

桌宠不提供独立模型接口，连接已有大肥鱼桥，复用其人格、记忆和语音。工作台、AstrBot 和 QQ 后台为本机页面嵌入，网页需要 WebView2。

在「连接设置」填写大肥鱼安装目录和两个本机后台地址。安装目录需含 `tools/workbench/server.py`；默认端口为 AstrBot 6185、QQ 后台 5099，可调整。后台分别按自身方式认证。没有部署服务时提供连接错误与配置入口，桌宠显示与本地动作本身不依赖在线模型。

SEEIN 不打包 QQ 账号、模型服务、AstrBot、SnowLuma 或大肥鱼个人安装。它们有独立来源、安装和服务条款。本插件说明的是连接能力，不代表赠送云端额度或保证任何账号登录。

## 生命周期、数据与排查

桌宠进程由托盘持有。工作台优先复用现有实例；SEEIN 自己启动的工作台解释器随托盘退出，原本独立运行的机器人服务不接管。隐藏桌宠保留运行，停止桌宠记住停用状态。

配置、记忆和素材导入位于 `%LOCALAPPDATA%\Seein\PetHome`；连接位置位于 `Companion/connections.json`。后台网页数据在同一用户数据根中。发布包只用固定上游默认素材，不打包本机对话、记忆或授权。

工作台无法连接先确认安装路径、Python 和服务状态；QQ 后台出现令牌页属于它自身认证，不由 SEEIN 绕过。语音与模型联网需求以外部服务配置为准。

上游：[dsh-pet](https://github.com/PC2005-cloud/dsh-pet)。大肥鱼另行按其安装说明配置；SEEIN 仅集成现有本机服务。
