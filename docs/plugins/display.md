# 副屏与主题库

## 2.2 安装方式

入口：主题库。此功能在 2.2 保持为一个完整插件，使用 `display-2.2.0.seeinplugin`，也可在插件中心直接勾选。


插件 ID：`display` · 版本：2.2.0 · 最低宿主：2.2.0 · 插件 API：1

入口：**主题库 → 我的主题／主题编辑器**。通过应用设置导入 `display-2.2.0.seeinplugin`，重启后生效。停用不删除设置，卸载保留用户数据。

## 功能

- 向受支持的串口副屏发送 JPEG 显示帧，不写固件和设备闪存。
- 内置主题与导入主题列表，模拟数据预览，应用、导入与删除；当前使用的主题先切换再删除。
- 可视化主题编辑器：新建、复制、打开、草稿恢复、保存、导出及保存并应用。
- 元素包括文字、图片、卡片、圆形、线条、时间、媒体封面与信息，以及传感器数字、进度条、仪表、环形和趋势图。
- 画布提供多选、拖动、缩放、旋转、对齐分布、网格吸附、分组、锁定、图层顺序、复制粘贴、撤销重做和组件预设。
- 背景支持 PNG/JPEG、GIF、MP4/WebM，提供裁剪、适应、填充及透明度；动态背景静音循环。
- 展示 CPU/GPU、内存、磁盘、网络、散热与耗能数据；媒体信息由用户会话读取，FPS 使用 PresentMon。

## 使用

1. 连接兼容副屏，在仪表盘确认连接；从主题库选择一个主题，预览后应用。
2. 编辑器的保存和预览不会改变副屏；「保存并应用」会等待后台确认结果。
3. Ctrl+Z 撤销，Ctrl+Shift+Z/Ctrl+Y 重做，Ctrl+C/V/D 复制粘贴/复制一份，Ctrl+G 分组，Ctrl+Shift+G 拆分；方向键微调，Shift 加方向键移动 10 像素。
4. 中键平移、Ctrl+滚轮缩放，Shift 等比缩放或按 15° 旋转，Alt 临时关闭吸附。输入框内不触发画布快捷键。

## 实现与上游

主题格式、编辑器、设备协议和调度在 SEEIN 中实现。SkiaSharp 负责绘制，原有 OpenCV/视频依赖负责背景解码；PresentMon 是独立的官方 FPS 辅助程序。不是导入另一个完整的主题编辑软件。对应 NuGet、PresentMon 版本和许可随组件清单提供。

## 边界、数据和排查

仅验证指定副屏协议，不能把串口存在当作型号兼容。没有传感器值时显示 `--`。主题 ZIP 校验路径、重复文件、大小和清单，禁止任意脚本。

系统主题位于 `%ProgramData%\Seein\themes`；编辑器草稿位于 `%LOCALAPPDATA%\Seein\ThemeEditor`。工程、导出和组件预设遵循用户配置的存储目录，不固定到某个盘符。设备断开先检查驱动、端口和型号；视频失败需检查文件格式与可用解码器。

## 体积与运行占用

发布附件中的 `COMPONENTS.json` 提供本轮实际文件字节数；`ACCEPTANCE.md` 区分已验证与未验证场景。运行占用随设备、主题、录制或播放负载变化，不承诺固定 CPU/内存数值。
