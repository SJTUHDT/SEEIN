# 截图录屏与 OCR

## 2.2 安装方式

入口：小工具 → 截图录屏。插件中心勾选后会自动加入 tools-common，共享适配层只安装一次；截图、录屏和 OCR 暂不继续拆包。


插件 ID：`capture` · 版本：2.2.0 · 最低宿主：2.2.0 · 插件 API：1

入口：**小工具 → 截图录屏；应用设置 → 快捷键管理**。通过应用设置导入 `capture-2.2.0.seeinplugin`，重启后生效。停用不删除设置，卸载保留用户数据。

## 功能

- 区域截图与标注、复制、当前窗口、当前显示器、延时及滚动长截图、截图历史。
- 屏幕录制及原工具提供的画面、声音、编码、保存偏好；录制能力以实际可用接口和设备为准。
- 离线中英文 OCR；截图翻译单独配置兼容接口，无密钥时离线 OCR 仍可用。
- 图片转 PDF，支持多图顺序和页面设置。
- 截图、标注、录屏窗口内快捷键，以及统一管理的全局呼出动作。

## 上游与修改

基于 mg-chao 的 Snow Shot / Snow Apps，固定提交 `7fecdb40a766e69f3a16b84c02e0fc50efc6e162`，锁定版本记录为 `v1.6.3_snow-shot`。原生操作窗口保留 Qt 界面；设置页、快捷键和生命周期由 SEEIN 统一管理。

SEEIN 增加当前用户私有命名管道、动作/设置/快捷键桥、受控子进程、保存目录与缓存策略、加密翻译密钥、文件索引与外部打开协调。上游截图、标注、录制和 OCR 算法没有改称 SEEIN 自研。

Snow Shot 等组件为 GPL-3.0-or-later；Ant Design Qt/绘图引擎、OCR 实现及依赖按各自许可。Qt、截图 FFmpeg 的源包与许可证独立提供。截图 FFmpeg 含 GPL 组件，不能与桌宠的 LGPL 精简 FFmpeg 混称为同一套。

## 使用与快捷键

在统一快捷键页分配需要的动作；新安装不抢占用户既有系统键位。支持的单键和组合键会校验冲突；F12 等系统保留键不支持。

双击**右 Alt**暂停/恢复截图全局快捷键，包含原有 Alt+A；暂停会注销注册，避免影响游戏。窗口内快捷键继续有效。双击**左 Alt**的剪贴板功能属于效率插件，二者分开管理。录入新快捷键时抑制已有全局动作。

## 数据、联网和边界

设置位于 `%LOCALAPPDATA%\Seein\Tools\snow`；图片、录屏、PDF、临时文件和缓存按存储偏好保存。翻译密钥用当前用户 DPAPI 加密，读取设置不返回密钥。离线 OCR 使用随包模型；翻译会向用户配置的服务发送识别内容，请按内容敏感性选择使用。

退出托盘先正常结束工具；仍在录制/导出时可能阻止退出以保护文件。历史文件和输出不会因卸载插件自动删除。黑屏或无声音应先检查窗口捕获、音频端点和系统权限，不承诺捕获受保护内容。

上游：[Snow Shot](https://github.com/mg-chao/snow-shot)。发布源码附带固定原始提交、实际修改后的源码和构建入口。
